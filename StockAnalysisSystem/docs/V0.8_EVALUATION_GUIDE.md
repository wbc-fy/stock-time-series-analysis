## 固定协议与单位

协议 ID 为 `v08_expanding_3x100_1`。原始 N 日中最后一个日线只提供最后目标收盘价；信号取零起始索引 N−301 至 N−2，连续三窗各100点，共300点。所有方法使用完全相同日期。训练集合逐窗扩张，标签日期必须严格早于该窗第一个信号日期；紧邻信号的一条训练候选被清除。每窗至少300个训练样本，warmup 不得重新移动评估边界。必须提供完整、显式可信交易所日历；不能用工作日猜测、填补缺日或自动补采。

固定23特征与 `v07_fixed_1` 保持不变。`zero_return` 的预测恒为0；Ridge 为 alpha=1、solver=svd，缺失值采用仅在该窗训练数据拟合的中位数（全缺失列为0）及训练专用 scaler；XGBoost 使用 V0.7 固定参数、单线程，无 eval_set、早停、搜索或按成绩重跑。总计六次模型拟合；不会替换 V0.7 生产模型。

`actual_return=close[t+1]/close[t]-1`，`horizon=1`，`target=next_trading_day_close_return`，`units=fractional_return`。例如0.01表示1%；DTO 保留小数收益，仅展示时转换一次。RMSE/MAE 同为小数收益单位；R² 无量纲且可以为负，实际收益恒定时为 null。总指标用300行重新计算，绝不能平均各窗 RMSE 或 R²。
